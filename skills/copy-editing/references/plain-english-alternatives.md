# Plain Word Alternatives

A working guide for swapping inflated wording for plain wording during a copy edit.

**About this guide.** It reflects general plain-language practice: the habits that most plain-writing advice has in common. It was written from scratch for this skill, and no specific published word list was copied or used as a starting point. The swaps are suggestions, not rules. Read the sentence, not just the word.

## How to use this guide

Edit by problem type, not by looking words up one at a time. If a sentence feels heavy, ask which of the seven patterns below it falls into, then apply that pattern's fix. Most heavy sentences contain two or three patterns at once, and fixing one often exposes the next.

Each table gives the wording to look for, a plainer option, and a note where the swap needs care.

---

## 1. Puffed-up verbs

Long verbs borrowed from formal registers. Each has a short everyday verb that does the same job.

| Look for | Try | Note |
|---|---|---|
| utilize | use | |
| commence | start, begin | |
| terminate | end, stop, cancel | Pick the one that matches what really happens |
| endeavor | try | |
| facilitate | help, make easier | Often better to name what is made easier |
| ascertain | find out, check | |
| demonstrate | show | |
| purchase | buy | Keep "purchase" as a noun in a checkout flow if the interface uses it |
| obtain | get | |
| require | need | "Require" fits rules and requirements |
| ameliorate | improve | |
| leverage (verb) | use, build on | Often hides a missing concrete claim |
| initiate | start, set off | |
| enumerate | list | |
| peruse | read, look through | |

**When the longer verb is right:** use "terminate" when you mean a formal, defined end (a contract, a process, a subscription with notice terms). "Require" is correct when something is mandatory rather than merely wanted.

## 2. Legal and bureaucratic phrases

Language that sounds official and makes readers feel they are being managed. Most of it can be said in everyday speech without losing accuracy.

| Look for | Try | Note |
|---|---|---|
| prior to | before | |
| subsequent to | after | |
| pursuant to | under, following | |
| in accordance with | under, following, as set out in | |
| in the event that | if | |
| notwithstanding | despite, even though | |
| aforementioned | this, that, or name the thing again | |
| forthwith | now, at once | |
| herein | here, in this document | |
| hereinafter referred to as | called | |
| shall | must (a duty), will (a future event) | Pick by meaning; "shall" blurs the two |
| in lieu of | instead of | |
| per annum | a year, yearly | |
| remuneration | pay | |
| adjacent to | next to | |
| failure to comply with | if you do not follow | Turn the noun into an "if" clause aimed at the reader |

**When the longer phrase is right:** in a contract or policy that a lawyer must sign off, settled terms of art protect meaning. Plain-language editing there means shorter sentences and clear structure, not necessarily swapping every legal term. Flag changes for review instead of making them silently.

## 3. Filler openers

Throat-clearing before the real point. Deleting the opener usually improves the sentence.

| Look for | Try | Note |
|---|---|---|
| It should be noted that | (cut) | State the thing |
| Please be advised that | (cut) | |
| I would like to take this opportunity to | (cut, or just say it) | "Thank you for..." works better than announcing thanks |
| At this point in time | now | |
| Needless to say | (cut) | If it is needless, leave it out |
| First and foremost | first | |
| In today's fast-paced world | (cut) | Start with your actual point |
| It is important to note that | (cut, or say why it matters) | |
| As a matter of fact | (cut) or in fact | |
| With that being said | but, however | |

**When the opener is right:** a short signpost helps in long documents ("Before the details, one warning:"). Keep it when it tells the reader how to read what follows, not when it only delays it.

## 4. Vague nouns

Abstract nouns that let a writer avoid saying what something is. The fix is usually to name the specific thing, which may need a fact you do not yet have. Ask for it.

| Look for | Try | Note |
|---|---|---|
| solution | the real thing: a tool, a service, a fix | Say what it does |
| offering | product, service, plan | |
| issue | problem, question, bug | Choose the honest word |
| stakeholders | the actual people: customers, staff, the board | |
| resources | money, people, time, tools | |
| initiative | project, plan, campaign | |
| capability | ability, feature | |
| functionality | features, what it does | |
| methodology | method | "Methodology" means the study of methods |
| deliverable | the thing handed over: report, file, design | |
| bandwidth | time, capacity | |
| touchpoint | contact, step: an email, a call, a visit | |
| factor | cause, reason, thing to weigh | |

**When the noun is right:** "stakeholders" is useful in a project plan that genuinely covers many groups and has not yet listed them. "Issue" is the standard term in some fields, such as publishing and law. Keep these where the audience expects them and the meaning is precise.

## 5. Stacked prepositions and wordy phrases

Several small words doing the work of one. Each pair or trio below can usually shrink to a single word.

| Look for | Try | Note |
|---|---|---|
| with regard to, in relation to, in respect of | about, on | |
| in the vicinity of | near | |
| for the purpose of | for, to | |
| on the basis of | from, because of, based on | |
| by means of | by, with | |
| in the course of | during, while | |
| at the present time | now, currently, or cut | |
| due to the fact that | because | |
| in order to | to | Keep "in order to" only to avoid a misreading |
| in excess of | more than | |
| a number of | several, some, or the actual number | |
| a majority of | most | |
| in spite of the fact that | although, even though | |
| in the near future | soon, or give the date | |
| prior to the start of | before | |

**When the longer phrase is right:** "in order to" is useful when a bare "to" would be ambiguous ("He went to London to meet the team" is fine; "To hire quickly, they posted early" is not clear). "In excess of" can appear in precise regulatory limits where "more than" would be read loosely.

## 6. Nominalizations

A verb turned into a noun, then propped up with a weak verb ("make", "give", "perform"). Turning it back gives shorter, more active sentences.

| Look for | Try | Note |
|---|---|---|
| make a decision | decide | |
| conduct an investigation of | investigate | |
| give consideration to | consider | |
| provide assistance to | help | |
| perform an analysis of | analyze | |
| reach an agreement | agree | |
| carry out a review of | review | |
| have a discussion about | discuss | |
| undertake the installation of | install | |
| is in need of | needs | |
| make use of | use | |
| take action | act | If you know the action, name it |

**When the noun form is right:** keep the noun when it is the subject of the sentence or when you need to count or describe it ("The analysis took three weeks"; "a thorough investigation"). The problem is a noun hiding an action, not nouns in general.

## 7. Hedges

Words that soften a claim. Some doubt is honest; most hedging is habit. Say the claim plainly, or state the real uncertainty once, with its reason.

| Look for | Try | Note |
|---|---|---|
| it would seem that perhaps | state the claim, or state the doubt once | Stacked hedges read as evasion |
| somewhat, rather, quite, fairly | (cut), or give a number | "Fairly fast" means nothing; "under two minutes" does |
| arguably | say who argues it, or commit | |
| tends to | drop it if always true; "usually" if mostly | |
| might possibly | might | |
| may potentially | may | |
| in some ways | name which ways | |
| we believe that | state the claim | Keep for a real opinion |
| essentially, basically, virtually | (cut) | |

**When the hedge is right:** when the evidence really is partial, say so, and say why ("based on 200 visitors"). Hedging claims about results, health, money and safety is often a legal or ethical requirement, not a style choice.

## When the longer word is the right one

Plain does not mean shortest. Keep the longer word when:

- **It is a defined term.** If a policy, contract or product interface uses a term consistently, changing it creates doubt about whether you mean something different.
- **It is the precise word.** "Terminate" a process, "approximately" in a measurement, "comprise" in a formal definition. A simpler word that blurs the meaning loses.
- **The audience expects it.** Medical, legal, technical and financial readers use specialist vocabulary as shorthand. Write for them in their register, and explain terms for everyone else.
- **Tone calls for it.** Condolences, formal notices and ceremonial text may suit a more formal register than a product page.
- **The short word repeats awkwardly.** If "use" appears four times in three lines, vary it. Rhythm and variety are fair reasons.
- **The short word has a different meaning.** "Commence" and "start" overlap, but "begin proceedings" and "start proceedings" can read differently in a legal setting.

When in doubt, ask who is reading and what they would say aloud to a colleague.

## Before and after

Each example combines several patterns. The changes are illustrative; always keep the writer's real facts.

**1.** *Before:* We utilize a proprietary methodology to facilitate the optimization of your onboarding experience.
*After:* We use our own method to improve your onboarding.
*Patterns:* puffed-up verbs, vague noun.

**2.** *Before:* Please be advised that, due to the fact that payment was not received prior to the commencement date, your access will be terminated.
*After:* We did not receive your payment before the start date, so your access has ended.
*Patterns:* filler opener, stacked phrases, puffed-up verbs, passive voice.

**3.** *Before:* It should be noted that a number of stakeholders have expressed concerns with regard to the timeline.
*After:* Three team leads are worried about the timeline.
*Patterns:* filler opener, vague nouns, stacked prepositions. The "after" needs the real number and who they are.

**4.** *Before:* In the event that you are in need of assistance, you should not hesitate to make contact with our support team.
*After:* If you need help, contact our support team.
*Patterns:* legal phrase, nominalization, filler.

**5.** *Before:* Our solution has the capability to make a significant improvement in your team's productivity.
*After:* Our scheduling tool helps your team plan shifts in half the time.
*Patterns:* vague nouns, nominalization. The "after" claims a specific result, so confirm it is true before using it.

**6.** *Before:* It would seem that this approach may potentially be somewhat more effective, arguably.
*After:* This approach probably works better, but we have only tested it on 200 visitors.
*Patterns:* stacked hedges. The "after" states the doubt once, with its reason.
